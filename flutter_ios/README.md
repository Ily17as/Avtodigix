# Avtodigix iOS (Flutter)

Flutter-версия приложения для iOS, повторяющая ключевую структуру Android-версии:

- нижняя навигация: **Подключение / Данные / Ошибки / Настройки**;
- режимы подключения Bluetooth/Wi‑Fi;
- экран live-метрик OBD;
- вкладки DTC и история отчётов;
- настройки пользователя (новичок/профессионал) и диагностический режим;
- онбординг при первом запуске.

## Запуск

```bash
flutter pub get
flutter run -d ios
```

## Что уже перенесено

- Поведение экранов и тексты на русском в стиле Android-приложения.
- Локальное хранение флагов/истории через `shared_preferences`.
- Симуляция OBD-данных для повторения UX (статусы подключения, MIL, DTC, метрики).

## Что нужно подключить для production

- реальный Bluetooth/Wi‑Fi транспорт OBD-II (через iOS-compatible плагины);
- нативные iOS permissions + background/network настройки;
- интеграция с бэкендом отправки feedback и полноценный экспорт отчётов.
